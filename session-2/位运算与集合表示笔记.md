# 位运算与集合表示（CS:APP 第2章）

> 来源：Bryant and O'Hallaron, *Computer Systems: A Programmer's Perspective*, Third Edition（CS:APP 第3版）
> 课件：General Boolean Algebras + Example: Representing & Manipulating Sets

## 1. 位运算：把布尔规则复制 N 份

- **核心**：一个数就是一小串 0 和 1（如 `01101001` 这 8 个位）。对它做位运算，就是把同一条布尔规则**一格一格地套在每一位上**，列与列互不影响。
- **四条规则**（C 语言运算符）：

| 运算 | 符号 | 规则 | 示例：A=`01101001`，B=`01010101` |
|:---|:---:|:---|:---|
| 与 AND | `&` | 两边都是 1 才是 1 | `01000001` |
| 或 OR | `\|` | 至少一边是 1 就是 1 | `01111101` |
| 异或 XOR | `^` | 两边不同才为 1 | `00111100` |
| 非 NOT | `~` | 1 变 0，0 变 1 | `10101010`（对 B 取反） |

- **为什么叫"每一位都套一遍"**：运算规则本身只管单个 0/1（真值表就是单位的规则），一整串数字能算，是因为每一位都单独套了一次规则。硬件里所有列同时算完。

## 2. 用位向量表示集合

- **约定**：第 j 位 = 1 → 元素 j 在这个集合里；第 j 位 = 0 → 不在。
- **索引方向**：位从右往左编号 0~7（最低位对应元素 0），红色索引 `76543210` 是看清这个约定的关键。
- **实例**：

| 位向量 | 对应的集合 |
|:---|:---|
| `01101001` | {0, 3, 5, 6} |
| `01010101` | {0, 2, 4, 6} |

- **集合运算 = 位运算**（一条指令算完）：

| 集合运算 | 位运算 | 结果位向量 | 结果集合 |
|:---|:---:|:---:|:---|
| 交集 ∩ | `&` | `01000001` | {0, 6} |
| 并集 ∪ | `\|` | `01111101` | {0, 2, 3, 4, 5, 6} |
| 对称差 (A−B)∪(B−A) | `^` | `00111100` | {2, 3, 4, 5} |
| 补集 | `~` | `10101010` | {1, 3, 5, 7} |

- **类比**：一排 8 个抽屉，编号 0~7，有东西记 1、空记 0。位向量 = 这排抽屉的状态记录，集合 = 哪些抽屉非空。

## 3. 手算示例：01101001 & 01010101 = 01000001

规则：**两位都是 1，结果才是 1；只要有 0，结果就是 0。** 上下对齐，一列一列单独算：

```
  0 1 1 0 1 0 0 1    ← 01101001
& 0 1 0 1 0 1 0 1    ← 01010101
  ↓ ↓ ↓ ↓ ↓ ↓ ↓ ↓
  0 1 0 0 0 0 0 1    ← 01000001
```

| 列 | 计算 | 是否都是 1 | 结果 |
|:---:|:---|:---:|:---:|
| 1 | 0 & 0 | 否 | 0 |
| 2 | 1 & 1 | **是** | **1** |
| 3 | 1 & 0 | 否 | 0 |
| 4 | 0 & 1 | 否 | 0 |
| 5 | 1 & 0 | 否 | 0 |
| 6 | 0 & 1 | 否 | 0 |
| 7 | 0 & 0 | 否 | 0 |
| 8 | 1 & 1 | **是** | **1** |

只有两边都为 1 的位置输出 1，其余全变 0。

## 4. 一句话核心

**位运算 = 把布尔规则复制 N 份，每一位各用一份；第 j 位 = "元素 j 在不在集合里"的开关，所以集合的交并补直接用 &、|、^、~ 一条指令算完。**
