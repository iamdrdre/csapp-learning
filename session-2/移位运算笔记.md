# 移位运算 Shift Operations（CS:APP 第2章）

> 来源：Bryant and O'Hallaron, *Computer Systems: A Programmer's Perspective*, Third Edition（CS:APP 第3版）
> 课件：Shift Operations

## 1. 核心：把 bit 串整体挪 y 个位置

- 移位运算：把一个 bit 串**整体往左或往右挪 y 个位置**，多出来的位按规则处理。
- **直觉：把 bit 当成一排小格子**。最左边是"高位"，最右边是"低位"。
  - 往左挪 = 每个格子里的数左移一格；最左边挤出去的格子**消失**；右边空出来的格子**默认放 0**。
  - 往右挪 = 每个格子里的数右移一格；最右边挤出去的格子**消失**；左边空出来的格子按规则补数。

## 2. 左移 `x << y`

- 左边挤出去的位：**丢掉**。
- 右边空出来的位：**补 0**。
- 效果：数值 × 2^y（前提没溢出）。
- **左移不需要分类型**：右边补 0 永远不涉及符号问题。

## 3. 右移 `x >> y`（分两种）

- 右边挤出去的位：丢掉。
- 左边空出来的位补什么，取决于规则：

| 类型 | 左边补什么 | 用途 |
|:---|:---|:---|
| **逻辑右移**（Logical shift） | 一律补 0 | 无符号数 |
| **算术右移**（Arithmetic shift） | 复制最左边的位（符号位） | 有符号数，保住负号 |

- 大白话：逻辑右移"无脑补 0"；算术右移"负数补 1、正数补 0"。

## 4. 两个示例对照（一步步摆格子看）

**例 1：`01100010 << 3`（左移 3 位）**

```
原始:  0 1 1 0 0 0 1 0
左移3: 0 1 1 |0 0 0 1 0|      ← 左边 3 个格子(0,1,1)挤出去，丢掉
剩下:       [0 0 0 1 0] 移到左边，右边补 3 个 0
结果:  0 0 0 1 0 0 0 0 = 00010000
```

**例 2：`01100010 >> 2` 逻辑右移 2 位（最左边是 0，正数）**

```
原始:  0 1 1 0 0 0 1 0
右移2: 0 1 1 0 0 0|1 0|      ← 右边 2 个格子(1,0)挤出去，丢掉
剩下:      [0 1 1 0 0 0] 移到右边，左边补 2 个 0
结果:  0 0 0 1 1 0 0 0 = 00011000
```

- 逻辑右移：左边补 **0**；算术右移：左边补**最左边那个数**。这里最左边是 0，两种补法结果一样（`00011000`）——这就是表 1 两行答案相同的原因。

**例 3：`10100010 >> 2`（最左边是 1，负数）**

```
原始:  1 0 1 0 0 0 1 0
右移2: 1 0 1 0 0 0|1 0|      ← 右边 2 个格子(1,0)挤出去，丢掉

逻辑右移（补 0）:  0 0 [1 0 1 0 0 0] → 00101000
算术右移（补1）:   1 1 [1 0 1 0 0 0] → 11101000
```

- 差别就在左边补的两位：**逻辑补 0，算术补 1（复制符号位）**。
- 为什么算术要补 1？最左边是 1 代表负数（补码表示），补 0 会把符号丢掉、变成正数；补 1 才能保持"这还是负数"。

## 5. 警告：Undefined Behavior（未定义行为）

- 如果移位次数 y **≥ 数据的位数**（如 8 位的 char 却移 9 位），结果是未定义的——程序可能干出任何事，不要这么写。

## 6. 为什么最左边的 1 代表负数（补码）

- 电脑表示带正负的数用的是**补码（Two's Complement）**：**最左边一位叫符号位，是 0 表示正数，是 1 表示负数**。
- 为什么选这个约定？因为**补码的加减法不需要电路区分正负**：
  - 8 位里 `11111111`（全 1）代表 **-1**，`11111110` 代表 -2。
  - 算 `-1 + 1`：`11111111 + 00000001 = 100000000`，第 9 位直接丢掉，剩下 `00000000` = 0——同一套加法电路，正负都能算对。
- 如果不补码、单纯拿最高位当"正负标记"，加法就得写两套规则。
- 大白话：**不是"1 天生代表负"，是工程师选了补码这种写法，让加减法共用一套硬件，代价是最高位的 1 被用来标记负数**。

## 7. 移位的实际用途

| 用途 | 大白话 | 例子 |
|:---|:---|:---|
| **快速乘除** | 左移 1 位 = ×2，右移 1 位 = ÷2，比乘除法指令快 | `x << 3` = x × 8 |
| **拆打包数据** | 把几个小数据塞进一个整数，用移位+与运算再拆出来 | 32 位整数存 RGB 三种颜色，移 16 位+& 取出红色分量 |
| **位标志（flags）** | 一个整数当一排开关，每一位是"开/关" | 文件权限：读=1，写=2，执行=4，`\|` 组合、`&` 检查 |
| **集合运算** | 位向量表示集合，移位就能遍历/构造集合 | 把元素 j 加进集合：`set \|= 1 << j` |
| **打散位（哈希/随机）** | 移位把位数搅乱，生成均匀的随机数/哈希值 | `x = x ^ (x << 13)` |

## 8. 一句话核心

**左移无脑补 0；右移分两种——逻辑右移补 0，算术右移复制符号位（保住负号）；正数时两种右移没区别，负数时才看出差别；移位次数不能大于位数，否则是未定义行为。**
