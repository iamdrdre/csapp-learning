# 二进制数表示与字节编码（CS:APP 第2章）

> 来源：Bryant and O'Hallaron, *Computer Systems: A Programmer's Perspective*, Third Edition（CS:APP 第3版）
> 两张课件：① 数怎么用二进制表示；② 字节怎么编码、为什么用十六进制

---

## 第一部分：二进制怎么表示数字

**核心一句话**：整数转二进制很干净；小数转二进制常常无限循环，存不精确；浮点数就是"规范化 + 舍入"的存储方式。

### 1. 整数转二进制（干净）

- **原理**：二进制里每一位代表 2 的某次方，把值为 1 的位加起来就是原数。
- **示例**：15213₁₀ = 11101101101101₂（14 位）
  - 2¹³+2¹²+2¹¹+2⁹+2⁸+2⁶+2⁵+2³+2²+2⁰ = 8192+4096+2048+512+256+64+32+8+4+1 = **15213** ✓
- **结论**：**整数都能精确转成二进制**，不会出错。

### 2. 小数转二进制（会无限循环）

- **原理**：十进制的简单小数，转成二进制可能是**无限循环小数**。
- **示例**：1.20₁₀ = 1.0011001100110011[0011]...₂
  - 方括号 `[0011]...` 的意思：**0011 永远重复下去**。
- **后果**：电脑存不下无限循环，只能截断或四舍五入 → **1.2 存进电脑后其实不是精确的 1.2**。
- **这就是 `0.1 + 0.2 ≠ 0.3` 的根源**。

### 3. 浮点数的科学计数法（规范化）

- **原理**：和十进制的科学计数法一个道理，把任意二进制数写成"1.几 × 2的几次方"的标准格式，这叫**规范化**。
- **示例**：1.5213×10⁴ = 15213₁₀ = 11101101101101₂ → 规范化后是 **1.1101101101101₂ × 2¹³**
  - 指数 13 怎么来的：原数小数点从最右边往左移动了 13 位。
- **用法**：浮点数（float/double，带小数的数）在电脑里就是按这个格式存的：**符号 + 小数位 + 指数**。
- **老师那句字幕**："怎么处理小数点右边的数字"——小数部分无限循环存不完，怎么办？答案：浮点格式**只保留有限的位数，其余舍掉**，舍掉就有误差。

## 第二部分：字节编码与十六进制

**核心一句话**：字节是电脑的最小存储单位；十六进制是"二进制的缩写"，程序员用它读写内存更省事。

### 1. 字节是什么

- **定义**：1 字节（Byte）= 8 个二进制位（bit），每个位只能是 0 或 1。
- **范围**：一个字节能表示 2⁸ = 256 种状态：
  - 二进制：00000000₂ ~ 11111111₂
  - 十进制：0₁₀ ~ 255₁₀
  - 十六进制：00₁₆ ~ FF₁₆

### 2. 三种数制对照表

同一个字节，可以用三种"语言"写出来：

| 十六进制 | 十进制 | 二进制 |
|:---|:---|:---|
| 0 | 0 | 0000 |
| 1 | 1 | 0001 |
| 2 | 2 | 0010 |
| 3 | 3 | 0011 |
| 4 | 4 | 0100 |
| 5 | 5 | 0101 |
| 6 | 6 | 0110 |
| 7 | 7 | 0111 |
| 8 | 8 | 1000 |
| 9 | 9 | 1001 |
| A | 10 | 1010 |
| B | 11 | 1011 |
| C | 12 | 1100 |
| D | 13 | 1101 |
| E | 14 | 1110 |
| F | 15 | 1111 |

### 3. 为什么用十六进制（核心）

- **原理**：**1 个十六进制位 = 4 个二进制位**，刚好能对上（F=1111 就是证明）。
- **效果**：8 位二进制写成十六进制只有 2 位，又短又不容易看错。
  - 示例：`01001101₂` → 拆成 `0100 | 1101` → `4D₁₆` = 77₁₀
- **类比**：写"1.2 万"比写"12000"省事，十六进制就是二进制的"万"。

### 4. C 语言怎么写十六进制

- **用法**：加 `0x` 前缀表示这是十六进制，字母大小写都行，`0xFA1D37B` 和 `0xfa1d37b` 完全等价。
- **注意**：`0x` 只是"告诉编译器这是十六进制"的记号，**不参与数值计算**。

```c
int a = 0xFA1D37B;   // 大写，清晰易读
int b = 0xfa1d37b;   // 小写，输入便捷
// 上面两个值完全一样
```

### 5. 和浮点数什么关系

- 浮点数（float/double）存在电脑里也是一串字节，字节怎么存、怎么看，就是这一页教的基础。
- 换句话说：这页是**地基**，后面讲浮点数就是在这块地基上盖楼。

---

## 两张课件串起来

1. **第一张**：数（整数、小数、浮点数）在二进制里长什么样 → 知道了数据怎么表示。
2. **第二张**：这些数最终存成字节，程序员用十六进制读写字节 → 知道了数据怎么读写。
3. 连起来就是：**浮点数 = 二进制科学计数法（规范化）+ 舍入误差；而它的存储单位是字节，字节用十六进制看最方便。**
