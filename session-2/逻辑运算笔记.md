# C 语言逻辑运算规则（CS:APP 第2章）

> 来源：Bryant and O'Hallaron, *Computer Systems: A Programmer's Perspective*, Third Edition（CS:APP 第3版）
> 课件：Contrast: Logic Operations in C（逻辑运算 vs 位运算）

## 1. 逻辑运算符与三条规则

- **运算符**：`&&`（与）、`||`（或）、`!`（非）
- **规则 1**：0 当成"假"，任何非 0 的数都当成"真"。
- **规则 2**：不看每一位，只看整个数是不是 0。
- **规则 3**：结果永远只返回 **0 或 1**（不像位运算返回一整串 8 位）。
- **规则 4（短路，Early Termination）**：能早算出结果就早停——
  - `a && b`：左边为假，右边**不执行**，直接返回假。
  - `a || b`：左边为真，右边**不执行**，直接返回真。

## 2. 与位运算的对比

| | 位运算 `&` `\|` `~` | 逻辑运算 `&&` `\|\|` `!` |
|:---|:---|:---|
| 操作对象 | **每一位**单独算 | **整个数**判断是不是 0 |
| 输出 | 一整串位（等长结果） | 只有 0 或 1 |
| 规则来源 | 布尔代数 | 真/假语义 |

## 3. 例子逐个解释（char 类型）

| 例子 | 过程 | 结果 |
|:---|:---|:---:|
| `!0x41` | 0x41 不是 0 → 是真 → `!真` = 假 | `0x00` |
| `!0x00` | 0 是假 → `!假` = 真 | `0x01` |
| `!!0x41` | 非 0 → 真 → 取反变假 → 再取反变真 | `0x01` |
| `0x69 && 0x55` | 两个数都不为 0 → 都是真 → 结果为真 | `0x01` |
| `0x69 \|\| 0x55` | 至少一个不为 0 → 为真 | `0x01` |

**注意**：`0x69 && 0x55` 的结果只有 `0x01` 一个位，而不是像位运算 `&` 那样得出 `0x41`——逻辑运算整体判断、只回 0/1。

## 4. `p && *p`：短路的安全用法（防崩溃）

- `p` 是指针，`*p` 是读取 `p` 指向的内容；若 `p` 是空指针（NULL），`*p` 会让程序崩溃。
- `&&` 的短路特性：**左边 `p` 为假（空指针）时，右边 `*p` 不执行**，直接返回假 → 程序不崩。
- 大白话：**"p 不是空指针才去读它的内容"**，一行代码写出一个安全检查。

## 5. 一句话核心

**位运算按位操作、输出一串位；逻辑运算整体判断——数只要不是 0 就算真，结果只有 0 或 1，还能短路省掉没必要的计算（如 `p && *p` 防空指针崩溃）。**
