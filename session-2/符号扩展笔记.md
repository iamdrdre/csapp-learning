# Sign Extension：符号扩展（CS:APP 第2章）

> 来源：Bryant and O'Hallaron, *Computer Systems: A Programmer's Perspective*, Third Edition

## 0. 一句话

**把短的有符号数变长时，把最左边的符号位复制 K 份垫在最左边——这样数值不变。**

## 1. 任务（Task）

- 手里有一个 w 位的有符号数 x。
- 要把它扩成 w+k 位。
- **数值必须一模一样。**

## 2. 规则（Rule）

- 把最左边那位（符号位）复制 k 遍，放在新数最左边。
- 其他位原样照搬。
- 公式：X' = 符号位×k 份 + 原来的所有位。

## 3. 为什么必须复制符号位，不能补 0

- 补 0 会毁掉负数。
- 例：8 位 `11111111` = -1。
  - 补 0 扩成 16 位：`00000000 11111111` = 255 → **数值错了**。
  - 复制符号位：`11111111 11111111` = 还是 -1 → **正确**。
- 正数：符号位是 0，复制 0 就等于补 0，也没问题。
  - `01111111`（127）→ `00000000 01111111`（127）。

## 4. 在哪遇到它

- C 语言把 `short` 赋给 `int`、把 `int` 赋给 `long`，编译器自动做符号扩展。
- 保证 -1 永远是 -1，不会在变宽时变成 255 之类的大数。

## 5. 完整规则：扩展与截断（Summary）

**扩展（小类型 → 大类型），数值保得住**

- 无符号：**高位补 0**。`0001` → `00000001`，数值不变。
- 有符号：**符号扩展**（复制符号位垫左边）。`1111`(-1) → `11111111`，还是 -1。
- 结论：两种都**符合预期**，数值不会变错。

**截断（大类型 → 小类型），数值保不住**

- 做法：**把高位的 bit 直接丢掉**，只留低 k 位，然后重新解释。
- 无符号 = **取模**（丢弃高位 = 对 2^k 取模）。
  - 例：`11011`（27）截断成 4 位 → `1011`（11）；验证：27 mod 16 = 11。
- 有符号：**类似取模**，但要看符号位，可能变负数。
- 结论：**只有数值小（塞得下）时结果才符合预期**；数一大，截断就会改值。

## 6. 一句话收尾

**符号扩展 = 变宽时复制符号位垫在左边；补 0 会把负数改错，复制符号位才能保持数值不变。扩展 = 值不变；截断 = 等于取模，值可能变。小数字安全，大数字出意外。**
